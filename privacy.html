Privacy policy

This OAuth client lets rclone, running on the owner's own computer, access the owner's own Google Drive.

  • Data accessed through Google APIs stays on the owner's computer and in their Google Drive. It is not sent to any server run by this app.
  • No data is collected, stored, shared, sold or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue on this site's GitHub repository.
